# TRVLTOO

**AI-powered day itinerary planner for Southeast Asia.**

Plan a personalised day in Thailand in seconds — choose your destination, travel style, budget, and area, and get a curated Morning → Afternoon → Evening itinerary generated by Gemini AI. Save trips to your account, export to PDF, and share a link with a rich social preview.

**[→ Open the app](https://mnotice.github.io/trvltoo/)**

---

## Features

- **AI Itinerary Generation** — Gemini-powered itineraries tailored to your persona, energy level, budget, and specific area within a destination
- **12 Thailand Destinations** — Bangkok, Phuket, Krabi, Chiang Mai, Chiang Rai, Koh Samui, Koh Phangan, Koh Tao, Ayutthaya, Hua Hin, Pai, Koh Lanta
- **Local Knowledge Base** — Curated travel intel per destination: best season, transport tips, where to stay, where to eat, what to avoid
- **Re-roll & Lock** — Swap any activity for an alternative, or lock ones you love before re-rolling
- **Save & Revisit** — Sign in with Google to save trips to your account and reload them any time
- **Export** — Download your itinerary as a PDF or Markdown file
- **Shareable Links** — Every saved trip gets a `/trip/:id` link with a full social preview card (OG + Twitter card meta)
- **Date Picker** — Quick-select today through the next 5 days, or open a calendar for future travel dates
- **Night Mode** — Toggle between light and dark themes

| Layer | Tech |
|---|---|
| Frontend | React 19, Vite 8, Tailwind CSS v4 |

| Hosting | GitHub Pages (app) + Firebase Hosting (share links) |

## Local Development

**Prerequisites:** Node.js 20+

```bash
git clone https://github.com/Mnotice/trvltoo.git
cd trvltoo
npm install
```

Create a `.env` file in the project root:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key

VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

- Get a Gemini API key at [aistudio.google.com](https://aistudio.google.com)
- Firebase credentials are in your [Firebase console](https://console.firebase.google.com) under Project Settings → Your apps

```bash
npm run dev      # start dev server
npm run build    # production build
npm run preview  # preview production build locally
```
